## 為什麼要重構？痛點整理

| 舊系統的問題 | 重構後怎麼改善 |
|-------------|--------------|
| `dbVOC.cs` 一個檔 4931 行，找東西靠 Ctrl+F | 每個功能獨立一個 service 檔，找 `dashboard_service.py` 就只看儀表板邏輯 |
| `List廠區0` `List廠區1` `List廠區2`... 根本不知道差在哪 | 函式名稱改成 `get_plant_list_for_dashboard()` 看名字就懂 |
| SQL 字串拼在 C# 裡，改完不知道有沒有壞 | SQLAlchemy ORM + Pytest，改完跑測試立刻知道 |
| 要改系統要先看懂 ASP.NET Web Forms | Python + FastAPI + Jinja2，現代技術棧 |
| 沒有文件 | `GET /docs` 自動產生 API 說明文件 |

### Phase 1：讓新系統可以跑起來（1-2 週）

**目標**：在本機成功啟動新系統，能看到首頁儀表板讀取真實資料

#### 1-1 設定環境

```powershell
# 進入 Python 重構目錄
cd VOC_Python_Rebuild

# 建立虛擬環境
python -m venv venv
.\venv\Scripts\Activate.ps1

# 安裝套件
pip install -r requirements.txt
```

#### 1-2 建立 .env 設定檔

把 `.env.example` 複製成 `.env`，填入真實連線字串：

```
# .env（不要 commit 這個檔案到 git）

# SQL Server 連線（VOC 主資料庫）
VOC_DB_DRIVER=ODBC Driver 17 for SQL Server
VOC_DB_SERVER=你的 SQL Server IP
VOC_DB_NAME=VOC
VOC_DB_USER=帳號
VOC_DB_PASS=密碼

# UTIDB（員工資料）
UTI_DB_SERVER=你的 SQL Server IP
UTI_DB_NAME=UTIDB

# Oracle CIM（唯讀）
CIM_HOST=10.10.22.192
CIM_PORT=1521
CIM_SERVICE=facpdb
CIM_USER=fac-cim
CIM_PASS=faccim

# 開發期間先開啟 Test Mode，不會真的發 Email/SMS
TEST_MODE=true
TEST_EMAIL=你的測試信箱@company.com
```

#### 1-3 測試連線是否正常

```powershell
# 跑測試看看
pytest tests/test_config.py -v

# 啟動開發伺服器
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

打開瀏覽器到 `http://localhost:8000` 應該看到新版儀表板。

#### 1-4 驗收標準

- [ ] 新系統可以啟動，不報錯
- [ ] 首頁能顯示廠區列表（即使是 Mock 資料也算）
- [ ] `http://localhost:8000/docs` 能看到 API 文件

### Phase 3：讓新系統可以登入（2-3 週）

**目標**：用公司 AD 帳號登入新系統，看到對應的廠區和按鈕

#### 3-1 完成 LDAP 認證

`auth_service.py` 目前是 Mock 登入，需要對接公司 Active Directory：

```python
# auth_service.py 需要實作這個函式
def authenticate_ldap(empno: str, password: str) -> UserInfo:
    # 連到公司 LDAP server
    # 驗證帳號密碼
    # 回傳員工資料（工號、部門、姓名）
    ...
```

需要確認：
- 公司 LDAP server 位址（舊系統 Web.config 裡有 `ldap://KH`）
- 可以用 `ldap3` 套件連線
- LDAP 搜尋 DN（問 IT 或看舊系統 AD 連線設定）

#### 3-2 實裝權限守門員

```python
# 目前 acl_service.py 的 check_permission() 是假的
def check_permission(empno, rights_id) -> bool:
    return True  # ← 這要改成真的查資料庫
```

每個 API 端點都要加上權限檢查：
```python
# 例如 spec_router.py
@router.post("/spec/update")
def update_spec(data: SpecUpdate, user = Depends(get_current_user)):
    if not acl_service.check_permission(user.empno, 權限.法規許可值與規格值維護):
        raise HTTPException(403, "沒有權限")
    ...
```

#### 3-3 驗收標準

- [ ] 用公司帳號可以登入
- [ ] 不同帳號看到不同廠區（依部門權限）
- [ ] 沒權限的按鈕不顯示

## 出問題先看這裡

| 問題 | 先查的地方 |
|------|-----------|
| 啟動報錯 | `.env` 有沒有設定正確？ |
| 資料庫連不上 | `database.py` 的連線字串 + 防火牆規則 |
| 燈號顯示錯誤 | `dashboard_service.py` 的比較邏輯 |
| 測試失敗 | `tests/` 目錄，`pytest -v` 看詳細錯誤 |
| 登入失敗 | `auth_service.py` 的 LDAP 設定 |
| 簽核流程卡住 | `flow_service.py` + 查資料庫 `VOC_closectl.status` |
