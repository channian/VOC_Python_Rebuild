# 首頁儀表板測試流程（Phase 1）

> 目標：確認新版 FastAPI 首頁能正確連上 DB、計算燈號、渲染表格。  
> 前提：虛擬環境與套件已安裝完畢。

---

## 步驟一：建立 `.env` 設定檔

複製範本並填入實際連線資訊：

```powershell
copy .env.example .env
notepad .env
```

至少要填的欄位：

```
VOC_DB_URL=mssql+pyodbc://帳號:密碼@資料庫IP/VOC?driver=ODBC+Driver+17+for+SQL+Server
TEST_MODE=True
```

> ⚠️ `TEST_MODE=True` 時，所有警報 Email / 簡訊會導向測試信箱，不會通知正式廠區主管。

---

## 步驟二：啟動服務

```powershell
.venv\Scripts\activate
python main.py
```

正常啟動後 terminal 應顯示：

```
INFO:     Uvicorn running on http://0.0.0.0:8000
INFO:     Application startup complete.
```

---

## 步驟三：開啟首頁

用 **Edge** 瀏覽：

```
http://localhost:8000/home
```

---

## 步驟四：逐項確認

### 4-1 基本畫面

| 確認點 | 期望結果 |
|---|---|
| 頁面能開 | 顯示表格，不是 500 / 白頁 |
| Header 有標題 | 顯示「廠務法規許可標準化管控平台」 |
| 倒數計時器 | 右上角顯示 `MM:SS`，每秒跳動 |

### 4-2 表格資料

| 確認點 | 期望結果 |
|---|---|
| 廠區欄有合併 | 同廠區多筆資料，廠區格合併成一格（rowspan）|
| 廠區有紅燈時 | 廠區格背景變為淡紅色 |
| 每列底色對應燈號 | 紅 / 橙 / 黃 / 綠 / 灰 整列底色正確 |
| 讀值欄底色 | SCADA = 米白、CWMS = 淺橙、QA手測 = 淺灰 |
| 斷訊 / 保養中列 | 整列灰色，讀值欄顯示斜線紋路 |
| N.D 顯示 | 讀值欄顯示 `N.D`，背景斜線紋路 |

### 4-3 燈號邏輯抽查

隨機抓幾筆資料，手動對照舊系統確認燈號一致：

| 讀值情況 | 期望燈號 |
|---|---|
| 讀值 ≥ OOS | 🔴 紅 |
| OOC ≤ 讀值 < OOS | 🟠 橙 |
| SCADA 管制值 ≠ SPEC 設定值 | 🟠 橙 |
| Alert < 讀值 < OOC | 🟡 黃 |
| 讀值 > 允收值 | 🟡 黃 |
| 其他 | 🟢 綠 |
| 斷訊 / broken≠0 / 無資料 | ⬜ 灰 `-` |

### 4-4 SCADA vs SPEC 比對（橙燈第二條件）

> 滑鼠**懸停**在讀值欄，tooltip 會顯示 SCADA 的 OOS / OOC / Alert 數值，  
> 與表格顯示的 SPEC 欄位比對，確認差異時是否確實亮橙燈。

## 步驟五：如果頁面掛掉

### 500 Internal Server Error

看 terminal 的完整 traceback，常見原因：

```
# DB 連不上
sqlalchemy.exc.OperationalError: ...
→ 確認 VOC_DB_URL 填寫正確、ODBC Driver 版本對

# 欄位名稱對不上
KeyError / AttributeError ...
→ 確認 VOC_SCADA_WEB / VOC_SPEC / VOC_plant / VOC_item 表結構與 SQL 一致
```

### 表格空白（無資料）

頁面顯示「尚無資料」而非 500，代表 DB 連上了但查無資料，或廠區 isShow=0。  
先到舊系統 `http://舊系統IP/VOC/Home.aspx` 確認有無資料，再比對 SQL 條件。

### 燈號對不上舊系統

記錄該筆的 `plantno`、`item`、`rvalue`、`OOS`、`OOC`、`alert`，回報給開發端調查。
