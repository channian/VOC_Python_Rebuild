## 七、出現錯誤時怎麼查

### Modal 開啟出現錯誤內容
HTMX 會把錯誤訊息填入 Modal，同時 terminal 有 Python traceback。

```
常見原因：
  500 → 看 terminal 的完整 traceback，通常是 DB 欄位名稱對不上
  422 → 表單格式錯誤（廠區隔離送出的已知問題）
  Modal 空白 → 按 F12 → Network tab，確認 /ui/* 請求有發出去且回應正常
```

### 快速確認 HTMX 請求

1. 按 `F12` 開啟開發者工具
2. 切到 **Network** 頁籤
3. 點擊任一 Modal 按鈕
4. 應看到一筆 `/ui/control`（或 `/ui/spec` 等）的 `GET` 請求
5. 狀態碼應為 `200`，Response 是 HTML 片段
